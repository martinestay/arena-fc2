# Arena FC-2

Juego de repaso para **Física Computacional II** (USACH, 2026): terminal y Git, Python, clases, NumPy, Matplotlib, pandas y lectura/escritura de archivos.

Todo el juego está en `index.html`, un solo archivo. Se abre en cualquier navegador; solo necesita internet para cargar las fuentes.

## Modos

- **Contrarreloj**: completa el código antes de que se acabe el tiempo.
- **Equipo contra el reloj**: reloj y vidas compartidas, por turnos.
- **Laboratorio de gráficos**: el código corre línea a línea y la figura se construye en vivo; encuentra el error y arréglalo.
- **Duelo**: 1 contra 1 o por equipos en el mismo teclado (Q W E R contra U I O P).
- **¿Qué imprime?**: predice la salida del código.
- **Ordena el programa**: arma el programa en el orden correcto.
- **Terminal Rush**: comandos de Unix y Git.
- **Simulacro de prueba**: 15 preguntas en 12 minutos, nota de 1,0 a 7,0.

Vidas a elección: muerte súbita (1), 3, 5 o ilimitadas. Los récords se guardan solo en el navegador de cada persona.

## Publicar con GitHub Pages

En el repositorio: **Settings → Pages**, «Source» = rama `main`, carpeta `/ (root)`. Queda en `https://TU-USUARIO.github.io/arena-fc2/`.
